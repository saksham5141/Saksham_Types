# Saksham_Types
This is a Multi themed typing learning software, as there are many typing learning software is available in the market but they are very expensive and it is not easy for everyone to buy them so i made a free open source typing software called as Saksham Types.
In this software we can learn complete typing and it comes with multiple themes(Cyberpunk Neon, Royale palace and retro) so it looks very interesting to lean typing and also i add typing games in it which will help us building accuracy and speed both.
